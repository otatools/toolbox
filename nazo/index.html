もんだい登録ツール（先生用）

  1. イラストを「004.webp」のように番号の名前で、index.html と同じフォルダに入れる（png・jpg でも可。答えをファイル名にしない）
  2. 下に番号・ファイル名・答えを入れると、登録用の1行ができる
  3. その1行を index.html の「FOLDERS」の中、入れたいフォルダの files の一覧のいちばん下に貼りつける
  4. フォルダを増やすときは「FOLDERS」の説明のとおりに { name: '...', files: [ ] }, を足す（name を '' にすると「フォルダ 2」のように番号だけになる）
